## Highest-risk remaining issue

Stable Codex authentication is file-backed. Mounting that file into the same
namespace as model-invoked commands would expose it, so the client now refuses
to launch. The next security milestone is a host-owned credential-injecting
proxy paired with the proven Bubblewrap filesystem shape, followed by an
authenticated live hidden-path and credential-denial test.
