# Devpost copy

## Title

CounterLab — CI for Understanding

## Tagline

Treat a learner's claim like code: test it against reality before merging the
repair.

## Short description

CounterLab turns a deceptively accurate ML notebook into an evidence-linked
Belief Test, immutable prediction, externally verified experiment, fixed
transfer task, and transfer-gated notebook patch.

## Longer description

A chatbot can explain leakage while a learner continues trusting the wrong
evidence. CounterLab makes the learner commit first, then lets a fixed kernel and
external verifier answer. Its customer-churn notebook looks excellent under a
random row split because customer identity crosses train and test. A whole-
customer split and identity ablation reveal the gap.

GPT-5.6 formalizes the claim into two evidence-linked hypotheses. Runtime Codex
compiles a bounded experiment declaration and public tests; it cannot compute
metrics or approve itself. A no-network, non-root candidate runner and frozen
host verifier decide whether a result may render. After the learner revises a
reusable rule, a surface-different forecasting transfer—not an LLM grade—unlocks
the smallest verified patch to a notebook copy. The final Reasoning Diff and
Proof Bundle connect belief, prediction, computed evidence, transfer, code, and
provenance.

The checked-in replay is genuine: an authenticated Codex run was rejected after
two repairs, and a separate later run passed 18 invariants and all 12 published
mutations. CounterLab labels both honestly and documents that generation-time
host read isolation remains partial.

## Judge instructions

1. Run `./scripts/clean-demo.sh` and open `http://127.0.0.1:5173`.
2. Choose Try Instantly for the complete no-secret learner path.
3. Choose Replay Verified Session to inspect the persistent label and genuine
   reject/repair plus later verified trace.
4. Use `./scripts/reproduce-session.sh leakage-01` to reproduce the candidate,
   canonical result, mutation matrix, and patch under Docker.
5. Inspect `docs/ACHIEVED_METRICS.json`; it contains executed software metrics,
   not invented learner outcomes.
