# Do-not-build list

The first-prize risk is not a shortage of features. It is an unsubmitted entry, an unqualified exact release, and a few credibility breaks in the core loop. The following work should not begin before submission unless every P0/P1 and release gate is green.

## Scope that weakens the thesis

- Generic chatbot answers, unrestricted tutoring, or a permanent chat transcript. CounterLab needs a Question that becomes a falsifiable comparison, not more explanation.
- Arbitrary subject generation, “all STEM,” or “works with any notebook” claims. Two narrow ML packs are the current truth.
- Additional adjacent ML misconception lessons. They add content count without proving cross-domain reuse.
- Probability, chemistry, arbitrary physics notebooks, `.py` intake, screenshots, arbitrary datasets, package installation, or networked notebook execution.
- Generated React/CSS/HTML/JavaScript/Python/SQL/shell or model-authored formulas/results. Generated components propose typed plans; fixed systems decide.

This does **not** prohibit the required trusted Lab Scene renderer. GPT-5.6/Codex may select schema-valid block IDs, narrative order, and allowlisted bindings; audited React components, fixed kernels, and the verifier own rendering behavior, values, and release. Build that bounded scene path for CL-023/CL-024. Do not turn it into arbitrary front-end code generation.

## Product bloat

- Accounts, authentication, profiles, multi-tenancy, social sharing network, public leaderboards, marketplace, badges, streaks, certificates, or generic gamification.
- Instructor dashboard, LMS/gradebook, classroom administration, cohort analytics, or institutional reporting.
- A voice tutor, native mobile apps, desktop packaging, browser extension, or ChatGPT App integration. A captioned, optionally narrated submission video is evidence packaging, not product scope.
- Global mastery graph, high-stakes grading/diagnosis/proctoring/hiring signals, or authorship detection.
- More navigation, agent panels, activity cockpits, debug dashboards, or permanently expanded evidence drawers.

## Technical work with poor deadline leverage

- Broad decomposition/refactoring of the 8,700-line Worker or large App module. Add a minimal CI gate now; refactor after submission with characterization tests.
- Dependency upgrades solely to silence warnings, scientific-engine replacement, new solver/library, or lockfile churn unrelated to a shipped verified pack.
- Rewriting the fixed kernels, scorer, verifier, replay format, or patch engine while their focused suites are green.
- Full identity/authorization platform. The bounded current need is capability-link disclosure and documented retention/revocation behavior.
- A bespoke PII classifier or security sandbox rewrite. First enforce declared privacy classes, common patterns, least disclosure, honest limitations, and a focused read-isolation boundary.
- Premature multi-region/queue redesign, new database, provider migration, or broad observability platform.
- Stock performance optimizations without measurement. Current LCP is strong; immutable caching is the smallest justified change.

## Submission theater to reject

- A staged verifier failure presented as a live failure.
- A deterministic replay presented as a fresh run.
- Sample values presented as live artifact evidence.
- A video recorded from a build other than the frozen public tuple.
- A screenshot that removes sample/replay/live labels or makes a local replay practice action look verified.
- Claims of Codex hidden-source unreadability until OS enforcement proves it; use the honest partial label.
- Claims of learner gains, mastery, retention, or completion without observed data.
- Claims of signed evidence when only integrity hashes are available.
- Claims that readiness/configuration health proves a completed journey.

## One conditional differentiation exception

The only defensible optional feature is exactly one fully verified cross-domain guided Subject Pack, `physics/free-fall`. It may begin only when:

1. CL-001 through CL-010 acceptance criteria are green;
2. one exact release tuple and current public journey matrix are retained;
3. no critical browser/test/security regression exists;
4. the full scientific-engine admission, oracle, unit, convergence, mutation, Boundary, transfer, Capsule, accessibility, and release plan fits before T−12h;
5. the team is willing to omit it completely if any gate fails.

A partial physics demo would weaken trust more than an honest two-pack scope.
