# Screenshot plan

Capture at 1440×1000 with real product state and no browser chrome where the
submission permits.

1. **Landing thesis** — product name, memorable line, three Judge Mode choices.
2. **Deceptive evidence** — 98.5% notebook output, Cell 3/output 0, seed and
   `customer_id` source evidence plus upload control.
3. **Belief Test** — side-by-side hypotheses, three evidence chips, decisive
   intervention and confirmation controls.
4. **Prediction Contract** — selected outcome, confidence, lock treatment.
5. **Genuine replay trace** — persistent Verified replay banner, SDK rejection,
   repair 1/2 failures, separate later verified run, partial generation-isolation
   disclosure.
6. **Verified reality** — three metric cards, honest bars/table, n/split/seed,
   zero group overlap and result hash.
7. **Transfer lock/pass** — forecasting case with patch locked, then deterministic
   pass.
8. **Patch and Reasoning Diff** — Cell 3 diff, unchanged-cell proof, four-column
   learner-facing diff, Proof Bundle export.
9. **Unsupported state** — uploaded notebook with typed magic/network reasons and
   disabled advance control.

Do not capture synthetic loading values, an unlabelled replay, private model
reasoning, credentials, local paths, or DevTools-only evidence.
